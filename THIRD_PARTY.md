# Third-party components

VeeTee 2350's own code is MIT licensed (`LICENSE`). These parts come from
elsewhere and keep their own licences; the firmware binary contains all of
them that are compiled in.

## Code

| Component | Where | Licence |
|---|---|---|
| PicoDVI (libdvi), Luke Wren | `lib/PicoDVI/` (vendored, patched: `PATCHES.md`) | BSD 3-Clause, `lib/PicoDVI/LICENSE` |
| libvterm, Paul Evans | `lib/libvterm/` (vendored, patched: `PATCHES.md`) | MIT, `lib/libvterm/LICENSE` |
| arduino-pico core, Pico SDK, Adafruit TinyUSB, SdFat | fetched by PlatformIO | LGPL / BSD / MIT (their packages) |

## Fonts

Built into the firmware (`lib/font/fonts_builtin.c`, generated by
`tools/ttf2psf.py` from `tools/fonts.toml`, which carries each font's
licence into the generated header):

| Fonts | Source | Licence |
|---|---|---|
| ati-smallw-6x8, rainbow100-80, nix8810-m16, fmtowns-8x16, fmtowns-8x8 | The Ultimate Oldschool PC Font Pack by VileR (int10h.org), converted to PSF2 | CC BY-SA 4.0 |
| notjam-clean-*, notjam-casual-*, notjam-prophet-* | Not Jam Mono fonts by Not Jam | CC0 1.0 |
| arbata-compact | Arbata Compact by Olga Yakovleva, rasterized and re-celled | CC BY 4.0 |

The PSF2 conversions in `fonts/psf/` are derivatives under the same
licences.

## Not part of the project

`external/` holds reference material and test suites used during
development (esctest2, vttest, Waveshare's demo code); each keeps its own
licence and none of it is built into the firmware.
